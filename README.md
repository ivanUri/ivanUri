## About me

I'm an independent software developer who enjoys exploring how the web works beneath the surface — from JavaScript engines and browser lifecycles to network protocols and automation infrastructure.

My main focus is **Koko**, an open-source, AI-first browser runtime built with **Zig and V8**. I'm interested in making browser execution more programmable, observable, and practical for AI agents, crawling, and testing.

- 🔭 **Currently building:** [Koko Core](https://github.com/ivanUri/koko-core)
- 🧠 **Exploring:** browser engines, web standards, runtime correctness, and reverse engineering
- 🛠️ **Working with:** Zig, V8, TypeScript, Node.js, C/C++, and browser protocols
- 💬 **Let's talk about:** browser internals, CDP, AI agents, and developer tooling
